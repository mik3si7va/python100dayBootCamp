# 100 Days of Python 🐍

A personal journey through Angela Yu's 100 Days of Python course.

This repository serves as both a learning log and a coding diary, documenting my progression from beginner Python projects to more advanced topics such as OOP, automation, data analysis, and web development.

Each folder represents a day of the challenge and contains the code, experiments, successes, mistakes, and lessons learned along the way.

Current status: Day 30/100 🚀

## 📅 Dev Log - 03 Jul 2026

Life has shifted gears over the last few days.

Starting a new job has completely changed my daily routine. Between adapting to a new environment, longer hours, commuting, and simply recovering my energy, I haven't been able to dedicate the same amount of time to coding as before.

At first, it felt frustrating. My momentum slowed down, and I could feel the difference compared to the pace I had built over the previous weeks.

But I've realized something important.

Momentum isn't measured by the number of hours you code. It's measured by the decision to keep showing up.

Even if I only manage to watch one lesson, solve one small problem, or write ten lines of code before going to bed, I'm still moving forward. Progress may be slower, but it hasn't stopped.

This project has become a reminder that consistency survives difficult seasons.

I'm building a career during the day while building my future at night.

One day at a time.
One lesson at a time.
One commit at a time.

The path is longer than I imagined, but every brick laid today is one less brick I'll have to lay tomorrow.

🐍 Day by day.
